# ediemurawski.com

Edie Murawski's portfolio site: plain HTML, CSS and a few lines of JavaScript, no build step.

- `index.html`: the whole site
- `images/`: artwork, project screenshots and photos
- `Edie-Murawski-Resume.pdf`: résumé linked from the site (no phone number)
- `favicon.svg`: browser tab icon
- `CNAME`: tells GitHub Pages to serve the site at ediemurawski.com
- `.nojekyll`: tells GitHub Pages to serve files as-is

To edit text, change `index.html` and push; GitHub Pages republishes automatically within a minute or two.
